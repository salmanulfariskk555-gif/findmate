# FindMate Web Preview

Responsive React + Vite website for the FindMate serious-relationship and marriage-intent platform.

## Run locally
```bash
cd web
npm install
npm run dev
```

## Build
```bash
npm run build
```

This is a front-end preview. Sample member cards are fictional illustrations. Registration, login, matching, messaging, profile uploads and backend API integration are not active yet.

## GitHub Pages
The repository includes a GitHub Actions deployment workflow. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source. The site will then deploy from the main branch to the repository's GitHub Pages URL.
