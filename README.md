# FindMate

A privacy-first matchmaking platform for adults seeking serious relationships and marriage.

## Project packages
- `web/` — responsive React website
- `mobile/` — Expo React Native Android app
- `backend/` — Django REST API foundation

## Status
Initial scaffold only. Authentication, matching, messaging, payments and production deployment are not live yet.

## Safety baseline
- Adults 18+ only
- Never commit secrets or real user data
- Keep profile visibility and contact details private by default
- Implement block, report and moderation workflows before public launch
